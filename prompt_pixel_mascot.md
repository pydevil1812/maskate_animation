# Задача: скрипт для генерации анимированного пиксельного маскота из фото

## Цель
Написать рабочий прототип (Python-скрипт или небольшое веб-приложение), который принимает на вход фотографию (например, фото питомца или любого объекта) и на выходе выдаёт анимированный пиксель-арт спрайт этого объекта — покачивающийся/подпрыгивающий, как маленький живой маскот.

## Пайплайн

1. **Растеризация в пиксель-арт**
   - Уменьшить изображение методом nearest-neighbor до маленького разрешения (например, 32×32 или 64×64 px).
   - Сжать палитру цветов через квантизацию (color quantization, k-means или Pillow `.quantize()`) до 8–16 цветов, чтобы получить классический пиксельный вид.
   - (Опционально) Выделить объект от фона перед пикселизацией — например, через rembg или Segment Anything, чтобы фон не мешал.

2. **Генерация кадров анимации (sprite sheet)**
   Пиксель-арт анимируется не деформацией, а сменой 3–4 дискретных кадров без интерполяции. Нужно сгенерировать эти кадры программно из одного силуэта, без ручной перерисовки. Два варианта на выбор (или оба):
   - **Squash & stretch**: кадр по очереди чуть сжимается по вертикали и растягивается по горизонтали (как мячик), с сохранением четких пикселей (nearest-neighbor масштабирование, без сглаживания).
   - **Волновой сдвиг**: изображение режется на несколько горизонтальных полос, и в каждом кадре полосы сдвигаются влево-вправо по синусоиде с разной фазой — получается «желейное» покачивание.

3. **Сборка спрайт-листа**
   Все кадры анимации собираются в один spritesheet (PNG-полоса кадров подряд).

4. **Проигрывание анимации**
   - На фронтенде: CSS `steps()` в `animation` на фоне-спрайте, либо Canvas с `drawImage`, переключающий кадры по таймеру.
   - Обязательно `image-rendering: pixelated`, чтобы браузер не сглаживал пиксели при масштабировании.

## Требования к результату
- Скрипт должен принимать путь к произвольному фото (JPG/PNG) на входе.
- На выходе — готовый spritesheet (PNG) + минимальный HTML/CSS файл-демо, который проигрывает анимацию в цикле, как маленький живой значок (по аналогии с анимированным крабиком-лоадером в интерфейсе Claude).
- Код должен быть по возможности простым и не требовать тяжёлых ML-моделей (базовый вариант без сегментации фона допустим — можно анимировать всё изображение целиком).
- Технологии на выбор: Python (Pillow, numpy) для генерации кадров + простой HTML/CSS/JS для демо-плеера.

Напиши рабочий прототип этого пайплайна: код генерации кадров из фото, сборку спрайт-листа и HTML-демо для проигрывания анимации.
