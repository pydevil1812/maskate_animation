# maskate

Превращает фото в анимированный пиксель-арт спрайт-маскот: покачивающийся
значок, как маленький живой персонаж.

## Установка на новой машине

Нужен Python 3.10+.

```bash
git clone https://github.com/pydevil1812/maskate.git
cd maskate
pip install -r requirements.txt
```

При **первом** запуске rembg молча скачивает нейросеть U²-Net (~176 МБ)
в `~/.u2net/`. Выглядит как зависший скрипт — это нормально, подожди.
В репозитории модели нет и быть не должно.

## Запуск

```bash
python pixel_art.py
```

Читает фото из `input/`, кладёт результат в `output/`.
Папка `output/` не хранится в git — она пересоздаётся из кода.

## Пайплайн

| Функция | Что делает |
|---|---|
| `ImageOps.exif_transpose` | разворачивает фото по метке EXIF (телефоны пишут поворот в метаданные) |
| `find_subject` | rembg вырезает объект, `getbbox` + `crop` обрезают по силуэту |
| `pixelate` | уменьшает до 64 px по ширине, LANCZOS (усреднение) |
| `quantize` | палитра до 16 цветов (median cut) + порог альфы для резких краёв |
| `make_frames` | 4 кадра squash & stretch по синусу, якорь по низу |
| `build_spritesheet` | кадры в один ряд, один PNG |
| `preview` | увеличение ×8 через NEAREST — **только для просмотра**, не часть пайплайна |

Правило, на котором всё держится: **уменьшаем с усреднением (LANCZOS),
увеличиваем без сглаживания (NEAREST).** Любой сглаживающий фильтр внутри
анимации вернёт полупрозрачные края и цвета мимо палитры.
