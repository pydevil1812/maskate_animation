# maskate

## Назначение

Утилита превращает фотографию в анимированный пиксель-арт спрайт-маскот: объект вырезается с фона, получает ограниченную палитру и несколько кадров лёгкой анимации.

## Пайплайн

1. Корректируется поворот фотографии по EXIF.
2. `rembg` выделяет объект и обрезает прозрачные поля.
3. Изображение уменьшается до пиксельной сетки.
4. Палитра ограничивается 16 цветами, прозрачность делается чёткой.
5. Формируются кадры анимации squash & stretch.
6. Результат сохраняется для просмотра и будущего spritesheet.

## Установка и запуск

Нужен Python 3.10+:

```bash
pip install -r requirements.txt
python pixel_art.py
```

Скрипт берёт исходные фото из `input/` и записывает результат в `output/`. При первом запуске `rembg` может загрузить модель U²-Net — это требует времени и интернет-соединения.

## Технологический стек

- Python
- Pillow
- NumPy
- rembg / U²-Net

## Статус и ограничения

Основные этапы пикселизации и анимации готовы. Генерация итогового spritesheet и HTML/CSS-плеер помечены как незавершённые. Результат зависит от качества исходной фотографии и точности автоматического отделения объекта от фона.
